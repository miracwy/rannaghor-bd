# Recipe data and media licensing checklist

This repository contains **website code and clearly marked demo/sample recipe records**. It does not include a ready-to-publish library of 10,000 licensed recipes.

Before importing or publishing a recipe, record:

- `license_name`: the exact license or permission basis (for example, the specific Creative Commons variant, a commercial license, or your own original content).
- `license_url`: a link to the full license terms where available.
- `source_url`: the original source URL when required or appropriate.
- `attribution`: author/creator/required acknowledgement and any attribution wording.
- Image rights: confirm the photo has its own compatible license; recipe text permission does not automatically grant photo permission.

Do not assume a web page, search result, recipe API, GitHub dataset, or a Creative Commons license permits every intended use. Read the actual license and attribution/share-alike requirements. Preserve source records, and do not scrape and republish websites without permission. For generated recipes, review factual accuracy, food-safety steps, ingredients and quantities before publication.

The bulk importer requires a non-empty `license_name`; the default import mode stores recipes as drafts. Enabling publish-on-import should be reserved for records that have already been reviewed and cleared for publication.
